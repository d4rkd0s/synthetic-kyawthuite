# Validation and characterization framework

This is an analytical checklist for participating laboratories, **not a validated test SOP**.

## Reference structure
From Kampf et al. (2017), natural kyawthuite: Bi³⁺Sb⁵⁺O₄, monoclinic I2/c; a=5.4624(4) Å; b=4.88519(17) Å; c=11.8520(8) Å; β=101.195(7)°; V=310.25(3) Å³; Z=4.

## Minimum criteria for claiming synthetic kyawthuite-like single crystal
- **Identity:** powder or single-crystal X-ray diffraction with indexed pattern/refined cell and comparison to authoritative structure/reference data. Assess polymorph and secondary phases, not just a peak overlap.
- **Chemistry:** Bi:Sb quantified with standards, measurement uncertainty, and appropriate elemental spectroscopy. Distinguish EDS screening from rigorous quantitative analysis.
- **Oxidation:** do not infer Bi³⁺/Sb⁵⁺ solely from elemental ratios; use defensible complementary evidence where necessary.
- **Single crystal:** verify crystal nature by diffraction, not only visually identifiable facets or shiny particles.
- **Provenance:** maintain specimen identifier, route, batch, equipment, analyst, dates, and full processing history.
- **Reproducibility:** repeat independent batch and archive raw instrument data, background/baseline decisions, and processing methods.

## Additional gem-oriented criteria
- Uncut maximum dimensions (three axes in mm), mass (mg or carat), calibrated scale images.
- Transparent/translucent/opaque recorded by optical method; report transmission wavelength range and measurement geometry.
- Inclusion count/type, cracks, strain, surface damage, cleavage planes, habit, color and color consistency.
- Document cuttable volume, test-faceting loss and finished gem results, if actually attempted.
- Clearly identify samples as **synthetic** when described externally.

## Decision tree
1. No verified BiSbO₄ identity -> reject identity claim, improve analytical confidence.
2. Phase verified but polycrystalline -> count as phase synthesis, *not* single-crystal growth.
3. Single crystal verified but heavily included -> count as crystal-growth result, *not* gem quality.
4. Optically suitable verified material -> candidate for independent gemological review.
