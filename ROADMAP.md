# Roadmap and stage gates

| Milestone | Description | Acceptance / exit gate | Status |
|---|---|---|---|
| M0 | Project charter and open-research scaffolding | README, evidence rules, contribution and safety documents | Drafted |
| M1 | Recover original growth papers | DOI/bibliographic records and source-verified conditions | Open |
| M2 | Independent crystal-structure reference | Reliable crystallographic files, characterization plan | Open |
| M3 | Laboratory feasibility and SOP approval | Qualified lab, hazard review, costing, approved SOP | Open |
| M4 | First independently verified reproduction | Structure/composition confirmation with raw data | Open |
| M5 | Crystal-growth optimization | Repeatable improvements and documented negative results | Open |
| M6 | Gem-oriented optical characterization | Transparent candidate and provenance report | Open |
| M7 | Open reproducibility publication | Methods + datasets independently replicable | Open |

No milestone is complete solely because a document describing it exists. Track stage-gate evidence in issues, link each acceptance artifact, and never imply successful laboratory work before measurements are released.
